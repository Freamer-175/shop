## 📌 Project Vision (Візія проєкту)

### 🎯 Проблема
Покупцям часто важко швидко знаходити потрібні товари, зручно переглядати детальні характеристики та оформлювати замовлення в одному місці без зайвих ускладнень.

### 💡 Рішення
**Web Shop App** — це легкий та зрозумілий веб-магазин, який дозволяє користувачам переглядати каталог товарів, шукати та фільтрувати продукти за категоріями, додавати їх у кошик та оформлювати замовлення.

### 👥 Цільова аудиторія
* **Покупці:** користувачі, які бажають переглядати та купувати товари онлайн.
* **Адміністратор (Продавець):** користувач з правами додавання, редагування та видалення товарів з каталогу.

---

## 🛠 Основний та додатковий функціонал (MVP)
- [x] **Створення даних:** додавання нових товарів (назва, ціна, категорія, опис, фото) адміністратором.
- [x] **Перегляд даних:** каталог товарів та детальна сторінка товару.
- [x] **Редагування та видалення:** зміна ціни, опису або наявності товару.
- [x] **Пошук та фільтрація:** пошук товарів за назвою та фільтрація за категоріями.
- [x] **Кошик та замовлення:** додавання товарів у кошик, підрахунок загальної суми.
- [x] **Перевірка даних:** валідація введених даних (ціна > 0, обов'язкові поля).
- [x] **Збереження даних:** збереження каталогу та замовлень у JSON/файлову базі даних.
